# Coperto. Стоп-лист

Веб-экран для кухни ресторана **Coperto**: текущее меню смены, фильтры по цеху и статусу, постановка блюда в стоп и возврат в продажу.

Демо: [coperto-stop-list-three.vercel.app](https://coperto-stop-list-three.vercel.app/)

Клик по строке открывает панель: причина и срок стопа, сохранение, снятие со стопа. Фильтры пишутся в URL, список обновляется сразу (оптимистично), при ошибке сервера строка откатывается.

Бэкенд — API Next.js, данные в памяти процесса. После простоя на Vercel список снова из начального набора — отдельной базы нет.

## Запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

```bash
npm test
npm run lint
```

## Стек

- **Next.js 16** (App Router) и **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- **TanStack Query** — кэш меню и мутации
- **Zustand** — панель и тосты
- **React Hook Form** и **Zod** — форма стопа и те же правила на сервере
- **Framer Motion** — панель и статусы
- **Vitest** — тест отката оптимистики

## Как устроено

```
app/                  страница, провайдеры, API
features/stop-list/   экран: таблица, фильтры, панель
entities/menu/        типы меню, схемы, HTTP-клиент
shared/               кнопки, селект, бейдж, тосты, слоты срока
```
